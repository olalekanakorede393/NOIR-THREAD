NOIR & THREAD — FASHION WEBSITE TEMPLATE

Thank you for purchasing NOIR & THREAD!

ABOUT
NOIR & THREAD is a modern fashion e-commerce website template built with HTML, CSS, and JavaScript. It features a clean design suitable for clothing and fashion brands.

FEATURES

- Responsive website layout
- Modern fashion homepage
- Product display section
- Shopping bag counter demo
- Newsletter form demo
- Collection and About sections
- Mobile-friendly design

FILES INCLUDED

- index.html — Website structure
- style.css — Website styling
- script.js — Button and form interactions
- images/ — Website images

HOW TO USE

1. Extract the downloaded ZIP folder.
2. Open the NOIR & THREAD folder.
3. Double-click index.html to open the website in your browser.
4. To edit the website, open the files using Visual Studio Code.

IMPORTANT
The shopping bag counter and newsletter form are front-end demonstrations. Online payments, order processing, and actual email subscriptions are not connected.
